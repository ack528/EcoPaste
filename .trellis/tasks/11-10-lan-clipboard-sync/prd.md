# LAN 剪贴板同步（6 位配对码）

## Goal

同一局域网内的多台设备（macOS / Windows 的 EcoPaste）之间自动同步剪贴板。设备通过类似微信输入法的 **6 位配对码**一次性配对，之后无需再次输入即可自动发现、互相同步。

## Requirements

### 配对

- R1 偏好设置新增「跨设备」页：开关、本机设备名、已配对设备列表、「查看匹配码」「关联设备」入口。
- R2 点击「查看匹配码」生成 6 位数字码，弹窗展示，**5 分钟有效、单次使用**；配对成功或过期后失效。
- R3 另一台设备点击「关联设备」输入 6 位码完成配对，双方设备列表出现对方（名称、平台）。
- R4 配对码不得明文在网络上传输；错误码尝试达到 3 次后该码作废（防在线爆破）。
- R5 已配对设备可重命名 / 解除关联；解除后对端自动失效。

### 同步

- R6 本机复制后，自动推送给所有在线的已配对设备；对端自动入历史并**直接写入系统剪贴板**（带回环抑制，不再次入库 / 不再次转发）。
- R7 类型：纯文本、HTML、RTF、图片、文件 / 文件夹。
- R8 文本与图片**立即传输**（受本机 `capture` 大小上限约束）；**文件不预传**：对端系统剪贴板先放「虚拟文件」，用户在任意应用（资源管理器、聊天软件等）按 Ctrl+V / 右键粘贴时才按需拉取内容。
- R9 标记为敏感（`is_sensitive`）的内容、被应用过滤规则排除的内容**不同步**。
- R10 设备离线时不排队；重新上线后只同步之后的新复制。
- R11 自动发现：同网段设备通过 mDNS 发现；已配对设备 IP 变化后自动重连。

### 安全

- R12 全部流量使用从配对码经 PAKE 协商并持久化的设备密钥做双向认证 + AEAD 加密；未配对设备无法读取内容。
- R13 仅 macOS + Windows。

## Acceptance Criteria

- [ ] 两台同网段设备：A 查看匹配码，B 输入后双方列表出现对方；错误码被拒；5 分钟后码失效；错码 3 次后失效。
- [ ] 重启任一端后无需再配对，自动重连。
- [ ] A 复制文本 / HTML / RTF / 图片，B 无需操作即可在任意应用粘贴，且 B 历史新增 1 条（不重复、不回环）。
- [ ] A 复制文件（含文件夹、含 ≥1GB 大文件），B 复制瞬间无大流量；在 B 资源管理器 Ctrl+V 时才开始传输并成功落盘，内容哈希一致。
- [ ] 敏感内容、被排除应用的复制不会发出。
- [ ] 抓包看不到明文内容；用错误设备密钥无法建立会话。
- [ ] `cargo clippy -- -D warnings`、`cargo test`、`pnpm lint` 通过；中英文文案齐全。
- [ ] 平台范围：Windows 完整实现；macOS 文本 / 图片同步完整，**macOS 虚拟文件（NSFilePromise）如无法在本机验证则显式 TODO**（见 AGENTS.md 平台约定）。

## Out of Scope

- 跨网段 / 公网 / 中继服务器；云同步。
- 历史记录全量回补、离线队列、冲突合并。
- 移动端。
- 对端接收到的文件进入本机历史列表（文件内容仅在粘贴时落到缓存目录）。
