# 云同步 + 云端服务器管理软件

## Goal

在局域网同步之外，提供**自托管云同步**：用户在自己的机器上运行 **EcoPasteServer**（Go 服务端 + Tauri 管理程序，结构参照 `D:\Projects\claude\MediaHub`），把服务端某个端口映射到公网后，任意网络下的 EcoPaste 客户端登录同一账号即可同步剪贴板，并能拉取云端保留的近期历史。

## Decisions（已与用户确认）

- 同步范围：新复制**实时推送** + 云端**保留近期历史**（新设备登录可拉取）。文件走按需拉取，云端只存清单 + 限额内的文件。
- 保密：**仅 HTTPS 传输加密**（服务器可见明文；不做端到端加密）。因此 `is_sensitive` 内容、被排除应用的内容默认**不上传**，沿用局域网同步的过滤。
- 形态：**Go 服务端 + Tauri 2 管理程序**，Windows 便携包；新建独立仓库 `EcoPasteServer`（`ack528/EcoPasteServer`），自动更新走 GitHub Releases（参照 MediaHub 的 `update`）。
- 服务端暴露公网：管理员建号（无开放注册），必须有登录限流 / 锁定、设备令牌、可吊销。

## Requirements

### 服务端（`EcoPasteServer/server`）

- R1 HTTPS + WebSocket。无域名场景：自签证书 + 客户端指纹固定（参照 MediaHub `tlsx`）；也允许挂用户自己的证书。
- R2 账号：管理员在管理程序创建 / 禁用 / 重置密码；口令 argon2id；登录发设备令牌，可逐设备吊销。
- R3 数据：SQLite（用户、设备、条目、保留策略）+ 磁盘 blob（图片、限额内文件）。条目去重按 `content_hash`。
- R4 保留策略（管理端可配）：每账号最大条数 / 天数 / 总容量、单图与单文件上限；超限按 LRU 清理，置顶 / 收藏条目不受影响（客户端本期不同步这两个标记，见 Out of scope）。
- R5 实时：设备在线时经 WebSocket 收到其它设备的新条目；离线期间的条目在重新连接时按 `since` 补拉。
- R6 防护：登录失败限流 + 递增锁定、请求体大小上限、每账号速率限制、审计日志。
- R7 自动更新（GitHub Releases，失败回退）与日志，参照 MediaHub。

### 管理程序（`EcoPasteServer/desktop`，Tauri 2）

- R8 页面：概览（在线设备、存储占用、端口 / 证书指纹）、账号、设备、存储与保留策略、日志、设置（监听端口、证书、更新）。
- R9 提供「证书指纹」与一键复制「客户端连接信息」（地址 + 指纹），供客户端填写。
- R10 启停 / 重启服务，托盘常驻，开机自启可选。

### EcoPaste 客户端

- R11 偏好设置「跨设备」页新增「云同步」分组：服务器地址、证书指纹（首次连接弹窗确认后固定）、用户名 / 密码登录、登出、连接状态、同步内容开关（沿用文本 / 图片 / 文件）。
- R12 与局域网同步并存：本机复制 → 同时推给局域网设备与云端；云端收到的条目写入剪贴板并入库，走 `WritebackGuard`，不回环；同一条内容经局域网和云端都到达时按 `content_hash` 去重。
- R13 新设备登录后可「拉取最近 N 条」（默认 50，可选）；之后只增量。
- R14 断线自动重连（退避），令牌安全存储，登出后清除。
- R15 文件：云端只存清单；其它设备粘贴时按需向云端拉取（沿用虚拟文件机制），服务端文件限额内才上传内容，否则提示不可用。

## Acceptance Criteria

- [ ] 管理程序创建账号后，两台不同网络的客户端登录同一账号，A 复制文本 / 图片，B 数秒内可粘贴；B 离线再上线后补齐期间条目。
- [ ] 公网侧：错误口令连续失败被限流 / 锁定；吊销设备令牌后该设备立即断开；明文 HTTP 不可用。
- [ ] 证书指纹不匹配时客户端拒绝连接并提示；首次连接需用户确认指纹。
- [ ] 保留策略生效：超过条数 / 容量后旧条目被清理，磁盘 blob 同步回收；敏感条目从不上传。
- [ ] 局域网与云端同时开启时无重复条目、无回环。
- [ ] 服务端 `go test ./...`、客户端 `cargo clippy -- -D warnings` / `cargo test` / `pnpm lint` 通过；中英文文案齐全。
- [ ] 发布：`EcoPasteServer` 便携包（含 WebView2Loader.dll）+ 更新包 + SHA256 校验和上传到 GitHub Release；EcoPaste 新版本包含云同步。

## Out of Scope

- 端到端加密、多租户公开注册、移动端、服务端内容搜索。
- 收藏 / 置顶 / 分组 / 备注的跨设备同步（首期只同步内容本身）。
- Linux / Docker 部署（后续可做，Go 本身可交叉编译）。
- macOS 云端文件虚拟粘贴（沿用局域网同步的 TODO）。
